Giving AI a Memory
so it remembers, tells the truth, and stays on task

We use AI to read, write, and fix code. But every new chat starts with no memory of the last one.

🧠

It forgets

Each time, we explain the project again. The AI searches the code again. This wastes time and tokens.

🌫

It guesses

If it does not know, it may guess. The answer can sound right but name files, settings, or actions that do not exist.

🧭

It loses focus

On long tasks, it can forget the goal, revisit old choices, or change more than we asked.

T · TaskOur goal

Our goal: give AI memory it can trust

No new tools or servers. Just text files kept with the code, shared with the team, and reviewed like code.

🔄

Remember

Pick up a task where we left off, without explaining it again.

✅

Stay honest

Use facts we can check, not guesses.

🎯

Stay focused

Follow the task, project rules, and current design.

Think of it as a notebook for AI: it reads the notes when work starts and updates them as it works.
A · ActionWhat I built

I built the Copilot Memory Bank extension

The memory-bank files

memory-bank/ ├─ projectbrief.md project goals and scope ├─ activeContext.md 1 current work and blockers ├─ progress.md 2 done, next steps, known issues ├─ systemPatterns.md design and code rules ├─ techContext.md tools and limits ├─ tasks/ notes from major tasks │ ├─ _index.md status + search words │ └─ 0000-template.md request, choices, result, checks └─ decisions/ └─ 0000-template.md template for numbered decision notes

1–2 = added to chat at the start when optional hooks are on. The task index finds a few related task notes.

Extension features

Set up➜Creates memory files and Copilot rules. Keeps files that already exist.
Populate➜/memory-init reads the code and fills in the memory files. Setup can open it for you.
Keep it current➜Update notes (/memory-update), plan work (/task-start), or remove old notes (/memory-prune).
Manage➜Commands open current notes or save a numbered note about a choice.
Integrate➜Optional hooks add notes to chat and check if memory needs an update. Settings can suggest the extension to teammates or keep current notes out of Git.
